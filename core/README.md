# 共享 Go 核心

此嵌套模块从桌面提交 `32a6c760` 的路由实现提取，供桌面与 iOS 共用。`routing` 仅依赖 Go 标准库，不依赖配置全局对象、文件路径、监听器或移动端网络栈。

桌面通过 `replace ... => ./core` 引用，移动端通过工作空间内相对路径引用；发布源码包须包含本目录。当前尚未发布独立模块版本，不能将本地 `v0.0.0` 声明理解为远端可下载版本。

在本目录执行 `go test -race ./...`。根模块的 `go test ./...` 不进入嵌套模块，因此 CI 单独运行核心测试。

保留原匹配、模式归一化和继承语义。匹配缓存增加 4096 项上限，超过上限清空后重建，超过 512 字节的查询键不缓存；这只改变缓存命中率，不改变匹配结果。纯核心不会记录原始路由数据，非法匹配项沿用跳过行为，导入层应在调用前执行校验。
